# Palette médicale / pharma

Palette composite en 5 couleurs, du vert aquamarin au bleu ciel.

| Nom | Hex | Usage |
| --- | --- | --- |
| Aqua | `#43C6B6` | Accent principal, traits de schémas, titres secondaires |
| Mint | `#9EE7D2` | Fonds légers, zones de validation |
| Seafoam | `#E8F8F4` | Fond clinique très clair |
| Sky | `#8FD3F4` | Flux, connecteurs, zones informationnelles |
| Sky deep | `#2F9FD0` | Titres, liens, éléments importants |

Texte principal :

- Ink : `#20343C`
- Muted : `#6A7D86`
- Line : `#D8ECEC`

Typographie :

- Garamond light si disponible ;
- fallback : `EB Garamond`, `Cormorant Garamond`, Georgia, serif.
